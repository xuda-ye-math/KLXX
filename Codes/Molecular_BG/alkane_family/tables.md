# Alkane-family ESS tables

Generated by `python build_table.py` from the accepted-stage metadata in each molecule's `artifacts` directory.

Each stage contributes a flow ESS. A sharpening ESS is included only when that stage changes the regularization parameters. The total factor is

$$\prod_s \frac{1}{\operatorname{ESS}_s},$$

where the product includes every flow step and each sharpening step that is actually used.
